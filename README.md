# 🎯 Evolução
Ao terminar o projeto, aprendi algumas coisas novas, como:
* Usar try e catch em JavaScript
* Usar a propriedade "readonly" em um input HTML
* Editar o conteúdo de inputs usando JavaScript
* Usar a pseudo-classe :active
* Alterar o cursor do mouse usando CSS
* Usar o sistema de cores HSL (Hue, Saturation e Lightness)
